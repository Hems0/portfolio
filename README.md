# How to update your portfolio

## Add a new project
Open `data.js` → find the `projects` array → add a new object:
{ title, description, bullets[], techStack[], githubURL, demoURL, featured }

## Add a certificate
Open `data.js` → find the `certificates` array → add:
{ name, issuer, date, link }

## Edit your bio
Open `data.js` → change the `about` string

## Update your photo
Replace `assets/photo.jpg` with your photo (keep the filename)

## Update your resume
Replace `assets/resume.pdf` with your new resume

## Deploy to GitHub Pages
Push all files to your GitHub repo → Settings → Pages → Deploy from main branch
